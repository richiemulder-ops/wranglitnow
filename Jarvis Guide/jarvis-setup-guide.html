One package: vault, Obsidian, assistant

Wranglit and Jarvis setup

Set up a personal knowledge vault that comes with a twelve-person AI team, open it in Obsidian, then build Jarvis on top: a voice butler that turns the vault into a 3D galaxy, answers from your notes, reads your calendar and hands work to the team. Everything runs on your own computer and your Claude subscription, and you never need a terminal: every step happens in the Claude desktop app, your file manager, Obsidian or the browser.

How it fits together

Part A · about 20 minutesThe vault and the team

Download Wranglit, open it in the Claude desktop app, and Larry interviews you for five minutes and files your people, projects and priorities.

Part B · about 10 minutesObsidian

Open the same folder in Obsidian, switch on the Wranglitdark theme and the Copilot plugin.

Part C · a few hoursJarvis

Twelve prompts in a second Code session build the voice assistant over your vault.

1. Prerequisites

Required
A Claude Pro or Max subscription

The team and Jarvis both run through Claude Code on your plan; no API key needed. Max is the better fit if you'll hand long jobs to the team.

Required
The Claude desktop app, signed in

From claude.ai/download, for Windows or Mac. All the work happens in its Code tab. Step A3 has Claude check the rest of this list on your computer and install anything missing, with your OK.

Required
Obsidian

Free from obsidian.md. You'll open the vault folder in it.

Required
Python 3.10 or newer

Jarvis runs on it, using the standard library only. Install it from python.org (on Windows, tick Add python.exe to PATH on the installer's first screen), or let Claude install it in step A3.

Required
Google Chrome or Microsoft Edge

Jarvis's voice input only works in these. Allow microphone access when asked.

Required
Internet, a microphone and speakers

Jarvis loads its 3D and markdown libraries from public CDNs, and Chrome's speech recognition runs online.

Recommended
Git

Larry offers to switch on local version history (a time machine for the vault) during setup, and that needs Git. Step A3 checks for it and installs it with your OK.

Recommended
A male British voice on your computer

Windows: Settings → Time & language → Speech → add English (United Kingdom), which brings "George". Or use Edge, which offers "Ryan (Natural)". Mac: System Settings → Accessibility → Spoken Content → System voice → add Daniel or Arthur.

Optional
Your logo as an SVG and your brand colours

Jarvis defaults to the Wranglit orange-on-black look. Change the colours below if you want your own.

Optional
Microsoft 365 connector on your Claude account

For Outlook calendar and email in Jarvis. Connect it in the Claude app under Settings → Connectors. To check, ask Claude in any Code session: "Can you see my Outlook calendar?"

Optional
A Fireflies.ai account

So Penn can fetch meeting recordings and file them, and Jarvis can show transcripts. Setup is step A7.

Part A. The vault and the team

Wranglit is a folder of plain markdown files plus twelve AI specialists (Larry the orchestrator, Penn who files, Pax who researches, and nine more) who know how to work in it.

Your vault will hold personal data. Keep it on your own computer or in a private cloud folder, and never upload it anywhere public.

Part B. Obsidian

  1. Open Obsidian and choose Open folder as vault, then pick your vault folder: {{VAULT_DIR}}.
  2. If asked whether to trust the vault's plugins, choose Trust author and enable plugins.
  3. Settings → Appearance → Themes: choose Wranglitdark.
  4. Settings → Community plugins → Turn on community plugins → Browse → search Copilot → Install → Enable. The vault expects it: each project's workspace lives at copilot/projects/<Name>/, which is the path the plugin uses.
  5. Have a look around: PKM/My Life holds what you told Larry, PKM/CRM your people and organisations, Actions/ the action register.
  6. Keep using the vault through Claude Code for a few days if you can ("file this meeting", "had a thought about…"). Jarvis has more to show you the more the vault holds.

Part C. Build Jarvis

  1. In File Explorer (Finder on a Mac), create the Jarvis folder you named above ({{PROJECT_DIR}}), next to the vault rather than inside it.
  2. In the Claude desktop app's Code tab, start a new session and choose the Jarvis folder, not the vault (in the vault, Claude becomes Larry).
  3. Claude asks before it runs commands or changes files. Approve them: that is how it builds Jarvis. You never type a command yourself.
  4. Paste the prompts one at a time, in order. Let each finish, then run through its "Check it works" list before the next.
  5. If something looks wrong, say so in plain words ("the voice is female", "the dots are blurry") and Claude fixes it in the same session.
  6. Prompts marked Optional can be skipped. Always run prompt 12, the final review.

Expect a few hours in total, mostly waiting on Claude. Each prompt takes it roughly 5 to 25 minutes.

Using it day to day

  • Talk to the team in a Code session in the vault folder, where Claude is Larry; or ask Jarvis to pass work to Larry ("Tell Larry to get Penn to file today's Fireflies meetings").
  • Start Jarvis by double-clicking the Start {{ASSISTANT_NAME}} shortcut on your desktop (prompt 1 makes it). A small window opens: that is Jarvis's server, so minimise it rather than closing it. The page opens at http://localhost:4700; use Chrome or Edge, and click anywhere to wake him.
  • After big changes made outside Jarvis, close that small window and double-click the shortcut again: it rebuilds the galaxy on start. Jarvis's own jobs and saved notes rebuild it automatically.
  • Close sessions with Larry ("close session") so he writes the session log and fixes drifted links.
  • Switch models from Jarvis's bottom-right panel: a faster one for quick answers, the strongest for team jobs.

Keeping it safe

  • Jarvis only listens on your own computer (localhost) and has no login. Don't open it to your network or the internet without adding one.
  • Jarvis's settings file and data are never served to the browser.
  • Outlook access is read-only: search and read, never send, reply or draft. Email content is treated as data, never as instructions.
  • The team writes to your vault under the vault's own permission rules. Keep version history on, and ask for narrow jobs ("today's meetings", not "everything").

Troubleshooting

What you seeWhat to do
Claude doesn't become Larry in the vaultMake sure the session was opened inside the vault folder, then say the activation line again (step A4).
The Wranglitdark theme isn't listedCheck the hidden .obsidian folder came across (File Explorer: View → Show → Hidden items). If it's missing, extract the ZIP again with File Explorer's own Extract All.
The voice is femaleInstall a British male voice (see prerequisites) or open Jarvis in Edge. Hover the 🔊 button to see which voice it picked.
The microphone does nothingUse Chrome or Edge, allow the microphone from the icon in the address bar, and open Jarvis at localhost.
Outlook says it has no accessCheck Settings → Connectors in the Claude app shows Microsoft 365 connected. Ask Claude in the Jarvis folder to confirm the Outlook calls set MCP_CONNECTION_NONBLOCKING=0 and don't pass --setting-sources "".
Calendar answers get the day wrongAsk Claude in the Jarvis folder to make sure every Outlook prompt includes the local time and UTC offset.
Answers take 8 to 15 secondsNormal: each answer starts the Claude CLI. Switch Jarvis to Sonnet or Haiku for speed.
New notes don't show in the galaxyClose Jarvis's small server window and double-click the Start shortcut again: it rebuilds on start.
A team job runs for agesIt is probably working through a backlog. Ask for a narrower job next time; the tray and context gauge show what it is doing.
"Address already in use" when starting JarvisJarvis is probably already running: just open http://localhost:4700. If not, another app uses port 4700; ask Claude in the Jarvis folder to change the port.
The page says it can't reach the serverJarvis's small server window was closed. Double-click the Start shortcut on your desktop.
Answers fail with a sign-in or "claude not found" errorOpen a Code session in the Jarvis folder and say: "Jarvis can't use the claude command. Check it is installed and signed in to my account, and fix it."
A model gives an errorYour plan may not include it. Pick another in Jarvis's model switcher.
