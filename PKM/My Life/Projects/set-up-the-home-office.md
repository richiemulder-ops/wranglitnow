# Set up the home office

> Sample note. It shows the shape a Project takes: bounded, with a finish line.
> Adapt it or delete it.

## Why this matters

Working from the kitchen table is costing a real amount of focus every day, and
the cost is invisible because it is spread thin.

## Definition of done

A room I can close the door on, with a desk, a chair that does not hurt after
three hours, and lighting that works on a dark afternoon. Done when I have
worked a full week in it without needing to move.

## Next steps

- Measure the spare room
- Decide desk vs standing desk
- Order the chair before anything else, it has the longest lead time

A Project completes and is then done forever. If this one never ends, it was a
Habit or a Key Element in disguise.
